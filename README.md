**Course:** B.TECH (CE-SE)  |

## 🚀 Project Overview

A decentralized crowdfunding platform built with blockchain technology (Solidity smart contracts) and modern web technologies (HTML, CSS, JavaScript).

## ✨ Features

- 6 Demo campaigns with real-time data
- Interactive donation system
- Campaign creation form
- Transaction history tracking
- 5 navigation tabs (Home, Campaigns, Create, History, About)
- Fully responsive design (works on mobile & desktop)
- Smart contract integration ready

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Tailwind CSS
- **Blockchain:** Solidity Smart Contracts
- **Web3:** Ready for Ethereum integration
